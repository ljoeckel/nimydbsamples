🏗️ Architektur & Frameworks

Frontend

Eingesetzt wurde React.js für ein reaktives UI, kombiniert mit Tailwind CSS für das Styling.

Backend

Eine robuste Node.js Umgebung mit einer PostgreSQL Datenbank sorgt für Datensicherheit.

Infrastruktur

Gehostet auf Vercel mit einer automatisierten CI/CD Pipeline über GitHub Actions.

💡 Besondere Merkmale

  • Performance: Optimiert auf einen Lighthouse-Score von 95+.
  • Accessibility: Vollständig barrierefrei nach WCAG-Standards.
  • Dark Mode: Intelligente Erkennung der Systempräferenz.
