📂 Sample: src/rss (RSS Live Feed)

A lightweight web application demonstrating how to capture, filter and display RSS data feeds.

There is no caching for the data. Always fetched from the Database.

Technical Highlights

  • Pure Backend Logic: All validation, persistence, and UI updates are handled strictly on the server side.
  • Real-time Feedback: Uses Server-Sent Events (SSE) to stream updates instantly to the browser.
  • Efficient Web Server: Powered by mummyDS multi-threaded HTTP server with Datastar extensions for high concurrency.

🚀 Quick Start

Launch the server directly using: nimble rss or go to src/rss and run nim c -r -d:ssl –threads:on –passL:“-L/usr/local/lib/yottadb/r203 -lyottadb” service.nim
